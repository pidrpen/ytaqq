# Конфигурация «Автозагрузка ЭСИ и выгрузка материалов»

Файл `Автозагрузка ЭСИ и выгрузка материалов-1.0.0.0.pmszcfg` импортируется
в Союз ПЛМ как обычная конфигурация. После импорта она оказывается в дереве
ZUM → Конструкторская часть.

## Что внутри

| Ключ | Что это | Что делает |
|---|---|---|
| `ZumExportMaterials` | команда | «Выгрузка материалов (наименование, обозначение)». Спрашивает, куда сохранить CSV, и выгружает обозначение, наименование, вид и id всех материалов. |
| `ZumExportMaterialsServer` | серверная функция | Выполняет отбор из `../queries/materials.sql` через `Service.MT.ExecuteReader` и читает у каждого объекта `Designation` и `Name`. |
| `ZumEsiAutoLoad` | автоматическое действие | Запускается по расписанию (тип повтора 3, как у `AutoRun` в «Базовой конфигурации для выгрузок», первый запуск 15.10.2026 в 22:00) и вызывает серверную загрузку ЭСИ. |
| `ZumEsiLoadNow` | команда | «Загрузить ЭСИ сейчас»: запускает ту же загрузку без ожидания расписания и показывает итог. |
| `ZumEsiAutoLoadServer` | серверная функция | Разбирает CSV-файлы в папке `C:\SoyuzEsiInbox` на сервере и заполняет состав сборок. |

Код всех пяти функций лежит в `scripts`, его можно читать и править.

## Файлы для загрузки ЭСИ

- Имя файла: обозначение сборки, например `АБВГ.123456.001.csv`.
- Внутри: `Обозначение;Наименование;Количество`, UTF-8, разделитель `;`.
  Пример лежит в `example.csv`. Строка заголовка пропускается сама.
- Поиск позиций и заполнение коллекции `Items` устроены так же, как в команде
  «Сформировать состав на основе Excel»: поиск по обозначению или наименованию
  в контейнерах 436 и 9, единица «шт», связь «конструкторская». Позиции, которые
  уже есть в составе, второй раз не добавляются.
- После обработки файл переносится в `Загружено` или `Ошибки`, и рядом
  с ним появляется `.log`, где по строкам расписано, что добавлено, а что
  не найдено.
- Путь к папке задаёт константа `InboxFolder` в `ZumEsiAutoLoadServer`.

## Как проверить

1. Импортируйте конфигурацию сначала в тестовую базу.
2. Запустите «Выгрузка материалов» и откройте CSV.
3. Создайте `C:\SoyuzEsiInbox` на сервере. Положите туда `example.csv`,
   переименованный в обозначение тестовой сборки, и нажмите
   «Загрузить ЭСИ сейчас».
4. Проверьте расписание в свойствах `ZumEsiAutoLoad` и поправьте его,
   если нужно другое.

## Как устроен файл

`.pmszcfg` — это двоичный пакет .NET (BinaryFormatter). `tools/build_pmszcfg.py`
берёт за основу `tools/template.pmszcfg` (это «Работа с параметрами изделия»
из pidrpen/cursor/pmszcfg), меняет в нём название, идентификаторы и функции
на свои и пишет новый файл. После правки `scripts/*.cs` пакет пересобирается так:

```
python3 tools/build_pmszcfg.py
```

Поле защиты конфигурации (ProtectionData) копируется из шаблона как есть.
Если Союз откажется импортировать файл из-за подписи, можно поступить иначе:
создать конфигурацию вручную и вставить в неё код из `scripts`.
