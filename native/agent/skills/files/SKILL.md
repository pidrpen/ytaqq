Навык: файлы CursorPad.
Путь рабочего стола получает программа; не собирай его по имени пользователя.
Новая папка без имени: new_folder; возвращённый @new используй во всех следующих действиях этой задачи.
У new_folder path — существующая РОДИТЕЛЬСКАЯ папка, name — имя новой. Не передавай создаваемую папку в path.
Если указан точный путь или имя назначения, используй mkdir с этим путём и размещай файлы прямо в нём; не добавляй лишнюю «Новую папку» внутрь.
Содержимое папки проверяй list/find. Данные другой папки из истории не доказательство.
Списки файлов в Excel создавай inventory, после переносов; это заполненный перечень, не пустая книга.
Результаты инструментов с пометкой НЕПОЛНЫЙ требуют продолжения чтения.
Перенос и копирование готовят план; отчёт о фактическом выполнении выдаёт программа после Применить.
