Навык: Excel CursorPad.
Сначала office_read: листы, заголовки, нужные строки и столбцы. Не выдумывай данные ячеек.
Пустая книга write не выполняет просьбу заполнить таблицу; используй excel_write или inventory для перечня файлов.
Именно ПУСТАЯ книга создаётся write path=...xlsx text=""; для неё не нужен excel_write, пробелы или формулы.
Формулу выводи из смысла задачи: проверь диапазон, единицы, пустые значения и контрольный пример.
Успешный пересчёт без ошибок не доказывает правильность выбранного диапазона или расчёта.
compare_materials ищет соответствие названий. Он не доказывает совпадение химсостава или взаимозаменяемость.
Для неподдерживаемых расчётов и отсутствующих данных СОЮЗ сообщай ограничение через ask.
