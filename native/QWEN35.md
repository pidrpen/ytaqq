# Средний уровень: Qwen3.5-4B Q4_K_M

С версии 2026.10.17.5 «Средний» скачивает `unsloth/Qwen3.5-4B-GGUF`,
ревизия `e87f176479d0855a907a41277aca2f8ee7a09523`.

- Файл `Qwen3.5-4B-Q4_K_M.gguf`, 2 740 937 888 байт.
- SHA-256: `00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4`.
- Каталог `%LOCALAPPDATA%/CursorPad/ai/models/qwen3.5-4b`.
- Старый `qwen3-4b` сохраняется. Его можно выбрать через «Обзор».
- Новая средняя используется для текста. Проектор изображений не загружается;
  уровень «С картинками» пока прежний.

Проверен llama.cpp **b11699, 7182ef71e**: `qwen35` загружается и отвечает через
Vulkan и CPU. CPU проверялся коротким запросом с контекстом 2048, агентные
задания — на Vulkan с контекстом 16384 и одним слотом. Проверен также настоящий
native-запуск CursorPad: аргументы Windows, авторизация и выдача инструмента.
Домашний RTX 5060 Ti 8 ГБ не заменяет проверку на рабочей Quadro 4 ГБ.

При первой загрузке новой средней обновляется управляемый движок llama.cpp;
свой вручную выбранный движок не заменяется. Для Qwen3.5 включён Jinja и
`enable_thinking=false`, в том числе серверное значение для запросов QwenPaw:
рассуждения не расходуют лимит короткого JSON-ответа до самой команды.

## Сравнение текущего агента, 17 октября 2026

Один прогон каждой модели: те же восемь русских заданий, QwenPaw 2.2.2,
реальные native-инструменты, MCP и XlsxWriter. Контекст 16k, один слот,
512 токенов основного ответа, температура 0.2, без рассуждений. Старый
Qwen3-4B Instruct-2507 Q4_K_M работает без рассуждений по своей архитектуре.
Три отклонённых вызова останавливают задание, как в настоящем интерфейсе.

| Задание | Qwen3-4B | Qwen3.5-4B |
|---|---|---|
| Новая папка, перенос Excel, заполненный перечень | прошёл | не прошёл |
| Новая папка, Word и перенос STL | прошёл | прошёл |
| 65 файлов из 34д с продолжением списка | прошёл | прошёл |
| Excel: 12, 3 и формула SUM | прошёл | не прошёл |
| Excel: оформление, фильтр, текстовые коды | прошёл | прошёл |
| «Создай в … папку» и перенеси каталог целиком | прошёл | не прошёл |
| «Создай папку в …» и перенеси каталог целиком | прошёл | не прошёл |
| Прямой перенос каталога в существующего родителя | прошёл | прошёл |

Итого **8/8 против 4/8**, отклонённых вызовов **0 против 9**. Суммарное время
восьми заданий — **244.56 с против 264.80 с**. Время включает Python, проверки
и Office; это не чистая скорость генерации и не статистический бенчмарк.
Неудачные задания новой модели не применялись.

Новая модель путала составную маску с @excel, параметры переноса каталога и
уточнения после правильного планирования формулы. Движок совместим, но текущий
агент с новой моделью пока менее надёжен. Это результат конкретного режима,
а не общий рейтинг интеллекта моделей; работа с рассуждениями требует отдельной
проверки. Автоматическое применение и обход «Применить» не добавлены.
