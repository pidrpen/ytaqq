CursorPad
=========

Плавающий блокнот, который следует за курсором Windows.
Права администратора не нужны. Ничего не устанавливается.

Как пользоваться
----------------
1. Запустите CursorPad.exe двойным щелчком.
2. Окно едет за курсором. Клики проходят сквозь него — можно работать как обычно.
3. Нажмите F8, чтобы закрепить окно и печатать в блокноте.
4. Внизу окна кнопки «Мечник» и «Рукавица» — это настройки курсора.
5. Нажмите F8 ещё раз, чтобы снова следовать за курсором.

Курсор
------
После закрепления (F8) внизу блокнота: Мечник / Рукавица.

Оба набора нарисованы целиком: раньше тематическими были только стрелка
и указывающая рука, остальные виды — одинаковые чёрные заглушки. Теперь
все шестнадцать в одном материале (сталь с латунью у Рукавицы, светлая
броня с золотом у Мечника), с тёмным контуром и светлой каймой, поэтому
видны и на белом, и на чёрном.

Каждый файл содержит размеры 32, 48 и 64 — Windows берёт нужный по
настройке размера курсора, а не растягивает мелкий.

Подменяются системные виды (пока программа запущена):

  стрелка           рыцарь / рукавица
  текст             полоска-клинок / полоска-палец
  ссылка / кнопка   указывающая рукавица
  ожидание          колесо загрузки
  фон. ожидание     стрелка + малое колесо
  справка           клинок + ?
  запрещено         кольцо с чертой
  точность          крест
  вверх             стрела
  булавка / человек запасные системные виды
  растягивание      стрелки (↔ ↕ ↘ ↗ ✥)

При выходе курсоры Windows возвращаются.

Окно компактное — видны около 5 строк. F9 сворачивает и возвращает.
Отдельная строка сверху — буфер последней копии (обновляется при Ctrl+C).
F3 ищет по этой строке (мини-ИИ, либо PLM / файлы если выбраны в Настройках).

Настройки (курсор, прозрачность, OCR, PLM) — кнопка «Настройки».
Поиск — отдельное окно (кнопка «Поиск» слева от «Настройки»):
строка запроса и где искать — Мини-ИИ, PLM или файлы.

Мини-ИИ (в самом .exe)
----------------------
Окно «Поиск» → «Спросить». Ходит в интернет (поиск + страница рецепта),
ответ у курсора. Нет сети — встроенные карточки.

PLM
---
Опция поиска «PLM». SQL: материалы 1767/20/39, исполнения 633, основной ТП 1794.
Файлы (сетевой диск Linux)
--------------------------
Кнопка «Файлы» в Настройках. Папку можно выбрать кнопкой «Обзор…» или
вписать руками; она запоминается (%LOCALAPPDATA%\CursorPad\files.txt).
Раз в час и по кнопке «Обновить JSON»: обход папки → files.json (без копирования файлов).
Смена пути пересобирает JSON. F3 ищет в JSON, открытие = Path + Filename.

Ограничений на глубину папок, количество файлов и размер индекса нет:
обходятся все вложенные папки, любой длины путь (включая длиннее 260 символов),
сколько бы файлов ни было — предел только память компьютера.
В списке находок показывается до 200 строк и общее число совпадений.

Пока идёт обход, в Настройках под строкой состояния бежит полоска,
а сама строка показывает, сколько файлов уже просмотрено. Кнопка
«Обновить JSON» на это время становится «Остановить» — обход можно
прервать. Прерванный обход ничего не портит: прежний индекс остаётся
на месте, а в строке состояния появляется «Обход прерван».

Индекс пишется во временный файл и подменяет прежний одним движением:
прерванное обновление не ломает работающий поиск. Если записать не удалось,
в строке состояния будет честное «Не удалось записать индекс», а не «обновлено».

Окно находок тянется за края, его размер запоминается. Щелчок по
заголовку столбца сортирует список, повторный — в обратную сторону
(стрелка показывает направление). По списку можно ходить стрелками,
Enter открывает.

В окне находок для файлов пять кнопок:
  Открыть файл    открыть двойным щелчком или этой кнопкой
  В проводнике    открыть папку с файлом и подсветить его
  Копировать      путь в буфер обмена
  В блокнот       путь в заметки
  Закрыть
Обновление
----------
Настройки → «Обновить с GitHub» (или пункт в трее). Сверяет public/version.txt
через GitHub API (если raw.githubusercontent.com недоступен — jsDelivr).
Скачивает CursorPad.exe и подменяет файл без прав администратора и без UAC.
Если папка программы недоступна для записи, новая версия кладётся в
%LOCALAPPDATA%\CursorPad\ и запускается оттуда.
Темы
----
В Настройках внизу восемь тем: четыре светлых (Светлая, Песок, Мята,
Роза) и четыре тёмных (Тёмная, Ночь, Графит, Уголь). У каждой свой
акцентный цвет, кнопки окрашены в цвет темы. Выбор запоминается.

Оформление плоское: ровные поверхности без рамок и теней, шрифт без
засечек, скруглённые углы, один акцентный цвет на действие. Окна
«Поиск», «Настройки» и «Находки» рисуют свои заголовки вместо
системных — их можно таскать за заголовок, закрывать крестиком
справа.
В строку — название, как в LIKE, например:
  Масло индустриальное И-12А ГОСТ 20799-2022
Ответ — список; двойной клик / «Открыть PLM» в уже открытый клиент
pmsz-plm:um-splmsrv:4450/IO.{InfoObjectId} (без [Windows-логина]).
и попытка открыть её в клиенте PLM.
Подключение: SQL-логин и пароль к UM-SQLSRV (не Windows-учётка).
Ссылка объекта: pmsz-plm:um-splmsrv:4450/IO.{id} — текущая сессия клиента.
Поля в Настройках: сервер SQL, база, пользователь, пароль.
Пароль хранится у вас в профиле (DPAPI), не в открытом виде.

Распознавание текста
--------------------
F6 — выделите прямоугольник на экране, Esc отмена.
Windows OCR читает фрагмент в фоне, текст попадает в блокнот
и в окно выжимки. В Настройках: «Выделить и прочитать».

Читает отдельный модуль CursorPadOcr.exe — он лежит внутри программы
и распаковывается в профиль при запуске, как и остальные вспомогательные
файлы. Отдельный процесс выбран намеренно: распознавание обращается к
системным кодекам, и сбой там не должен утаскивать блокнот с заметками.
PowerShell больше не нужен (в организациях его часто ограничивают
политиками), но прежний скрипт остаётся запасным путём.

Перед распознаванием снимок увеличивается втрое и выправляется по
контрасту — экранный текст читается заметно точнее. Длина ответа больше
не ограничена: раньше он молча обрезался примерно на странице.

Если распознавателя нет, программа говорит об этом прямо — «нет пакетов
распознавания, добавьте язык в параметрах Windows» вместо прежнего
безликого «текст не распознан».

Или не открывая окно:
  F7  следующий курсор
  F6  распознать текст
  правый клик по значку в трее

Быстрая вставка
---------------
Каждая непустая строка блокнота — шаблон.

  Ctrl+1  вставляет 1-ю непустую строку в активное окно
  Ctrl+2  вторую
  …
  Ctrl+9  девятую

Пустые строки пропускаются. Сначала скопируйте шаблоны в блокнот (F8),
затем снова следуйте за курсором и жмите Ctrl+1 в любом поле ввода.

Картинка: закрепите F8, Ctrl+V в строку — появится IMG:N и миниатюра.

Если F8 занята другой программой, CursorPad автоматически возьмёт Pause или Scroll Lock. F9 сворачивает окно.

Автозапуск — галочка в Настройках. Пишется в ваш профиль Windows
(HKCU Run), права администратора не нужны.

Второй запуск не плодит окон: поднимается уже работающий экземпляр.

Правый клик по значку в трее:
  Закрепить / Следовать
  Курсор: Мечник / Рукавица / обычный Windows
  Выделить и прочитать (F6)
  Открыть файл заметок
  Выход

Заметки сохраняются в:
  %LOCALAPPDATA%\CursorPad\notes.txt

Windows SmartScreen
-------------------
При первом запуске может появиться «Windows защитила компьютер».
Это обычное предупреждение для программ без цифровой подписи.
Нажмите «Подробнее» → «Выполнить в любом случае».

Технически
----------
- Не требует установки и прав администратора (asInvoker).
- Не ставит хуки клавиатуры: только RegisterHotKey + GetCursorPos.
- Курсор меняется через SetSystemCursor на время работы программы.
- Если процесс убить, при следующем запуске схема Windows восстанавливается.
- Закрывается из трея или кнопкой × после закрепления (F8).
